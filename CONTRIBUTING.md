# Contributing

## Prerequisites
- JDK 21

## Setup
```bash
./gradlew --version
```

## Validate changes
```bash
./gradlew test buildPlugin
```

## Run IDE sandbox
```bash
./gradlew runIde
```

## Packaging
```bash
./gradlew buildPlugin
```

Output ZIP:
- `build/distributions/webstorm-sdf-account-status-0.1.0.zip`
